Define an action

Local actions run through an argv array with no shell, so parameters cannot become extra arguments. SSH commands are handed to the remote login shell, which is why every SSH parameter must carry a pattern.

A JSON list of tokens. A parameter is written {name} and must be a whole token on its own — --name={x} is refused, because that is how one parameter becomes two arguments.

JSON. Each parameter may set type (string, integer, choice), pattern, choices, min, max, required and secret. A pattern matching everything is refused — it looks like a constraint and is not.
